# 趋势跟踪假设卡与 Walk-forward 验证

趋势跟踪研究可以用突破入场与波动率止损检验一个假设：扣除交易摩擦后，趋势收益是否足以弥补震荡期的反复止损。以下是可填写的实验模板。

| 假设要素 | 实验记录 |
|---|---|
| 对象 | 交易所、标的、K 线周期、区间、来源、数据版本 |
| 触发 | 收盘突破此前一段时间的最高价，最早在下一根 K 线成交 |
| 观察窗口 | 持有至跌破退出通道、触发跟踪止损或样本结束 |
| 对照 | 同一段时间、同样资金口径的买入持有 |
| 指标 | 样本外总收益、最大回撤、Calmar、交易次数、胜率与盈亏比 |
| 否定条件 | 预先定义对照门槛、最低交易次数、邻域敏感性和成本容忍度 |

用较早的训练窗选择参数，在其后互斥的测试窗中逐折执行。每折独立初始化策略，事先声明跨折是否延续仓位和资金。逐折记录收益、成本、交易数、参数和全部试验，再按一致的权益口径拼接样本外结果。

固定区间网格作为对照时，要标明每折是否有成交。空仓可能降低回撤，但也会错过上涨。按周期、趋势与震荡环境分别报告结果，手续费和滑点使用预先冻结的基准与压力情景。交易次数低于预设门槛时，记录为证据不足。

相关方法见 [研究方法](01-量化研究方法论与安全边界.md) 和 [回测工程](02-数据与回测工程规范.md)。
