# UMP 统计拦截器

受 abu 的 UMP（失败交易拦截）思路启发，可用决策时已知的 RSI、距此前高点的距离、波动率分位等特征对信号分桶，识别历史上表现较弱的情境。开仓时记录特征，交易完成后再登记扣除费用的结果。

1. 在训练段固定特征、桶边界、最低样本量和拦截阈值。稀疏情境单独标记为证据不足。
2. 将冻结后的统计用于后续测试段，对比启用前后的拦截数量、净收益、回撤、交易次数和胜率。若没有拦截，记录为无可观察的增量。
3. 按时间滚动复验，检查成本、样本跨度、K 线周期与桶边界的敏感性。胜率提升要结合盈亏比和被拦截的盈利机会解读。

拦截器也有拟合风险。运行中更新统计时，应确保每次决策只读取当时已经完成并可见的交易，并保留统计版本和拒绝原因。

相关方法见 [趋势跟踪验证](10-趋势跟踪假设卡与WF验证.md) 和 [数据与回测工程](02-数据与回测工程规范.md)。
