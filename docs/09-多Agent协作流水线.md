# 多 Agent 协作流水线

把交易研究拆成情报、分析、风控和执行四个环节。每个环节记录输入产物、处理时间、结果和依据，使一笔订单可逆向追溯到信号与数据。

| 环节 | 输入 | 输出 |
|---|---|---|
| 情报 | 公开行情、公告、新闻 | 带来源和可见时间的简报 |
| 分析 | 简报、已收盘行情、规则卡 | 结构化信号、证据及数据缺口 |
| 风控 | 信号、敞口、资金和限额 | 批准、缩减或拒绝的决议及仓位计算 |
| 执行 | 获批决议、当前账户与市场状态 | 执行记录、成交与对账结果 |

- 每个产物使用可追溯的 ID 指向上游版本。来源缺失时标记待核实，并保留空简报、拒绝和未执行等结果。
- 信号置信度描述模型对其解释的确信程度。用于仓位模型的历史统计需记录样本量、窗口和计算口径。
- 执行前复核审批、当前仓位、限额与模式。交易阶段晋级与异常处置由人工负责。
